# Tag Rules

Vault 全体で使うタグ体系。

| タグ | 意味 |
|---|---|
| `#llm-draft` | AIが生成した叩き台。人間の確認待ち |
| `#wiki` | LLM-Wiki 統合ページ。複数ノートの横断統合 |
| `#paper-relevant` | 論文執筆に関連するノート |
| `#open-question` | 未解決の問い・追加実験が必要な事項 |
| `#claim` | 論文の主張として使用中または候補のアイデア |
| `#established` | 文献・実験で十分に裏付けられた知識 |
| `#hypothesis` | 自分が立てた仮説。未検証 |
| `#my-interpretation` | データや文献への独自解釈 |
