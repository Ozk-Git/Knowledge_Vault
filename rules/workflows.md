# Workflows

AGENTS.md の操作定義の詳細手順。

## Remember — 議論の記憶保存

**目的**: セッションで決定した設計方針・背景・判断を Vault 内に保存し、端末・AI エージェントをまたいで再現性高く引き継げるようにする。

**手順**:

1. 現セッションの決定事項・設計方針・背景を整理する
2. 保存先を判断する:
   - 特定ディレクトリの作業に関する内容 → そのディレクトリの `context/` 内に保存（例: `Papers/slug/context/design-decisions.md`）
   - Vault 全体・複数ディレクトリにまたがる内容 → `rules/session-memory.md` に追記
3. 以下の形式で記録する:
   ```
   ## [YYYY-MM-DD] {トピック}
   ### 決定事項
   ### 背景・理由
   ### 今後の方針
   ```
4. どの AI エージェントでも解釈できる平易な Markdown で記録する（AI 固有の構文を使わない）
5. `log.md` に保存先と概要を記録する（形式: `## [YYYY-MM-DD] Remember | {保存先} — {概要}`）

## Connect — セレンディピティ探索

- 2週間以上前の Permanent ノートと最近追加されたノートの予期しない接続を探す
- 孤立ノート同士に潜在的な関係があれば提示する
- 提案は候補列挙にとどめ、採否はユーザーが判断する
